# AI 활용 단계
1. AI에게 어떻게 명령을 내려야 효율적으로 내릴 수 있을지 물어봄
   <img width="792" height="117" alt="image" src="https://github.com/user-attachments/assets/1e17a272-9b9d-47cd-a95c-2ac24a70d93b" />    
   >한 번에 "다 만들어줘"라고 하기보다 **작은 동작 단위로 나눠 지시하고, 단계마다 실제 사이트에서 검증**하는 것이 좋습니다. 공고 사이트마다 폼 구조가 달라 초반 설계가 어긋나면 나중에 고칠 부분이 커지기 때문입니다.  
   >## 1단계: 요구사항과 범위 확정  
   >처음에는 지원할 사이트를 2~3개로 좁히세요. 원티드 같은 플랫폼과 기업별 채용 페이지는 구조가 많이 다릅니다.  
   >> 채용 지원 폼 자동 입력 에이전트를 만들려고 해. 입력은 공고 URL과 추가 정보이고, 대상 사이트는 A, B, C야. 최종 제출은 내가 직접 해. 코드는 아직 작성하지 말고, 요구사항 문서와 모호한 점에 대한 질문부터 정리해 줘.  
   >## 2단계: 설계  
   >> 브라우저 자동화 방식, LLM의 역할, 이력 데이터 저장 방식을 대안과 함께 비교하고 하나를 추천해 줘. 폴더 구조와 모듈별 책임도 알려줘.  
   > 제가 추천하는 구조는 다음과 같습니다.  
   > ```text
   > URL 입력 → 폼 필드 추출 → LLM이 필드와 이력 항목을 매칭  
   > → 코드가 입력 → 사람이 검토 후 제출  
   > ```  
   > LLM은 '어떤 칸에 어떤 값을 넣을지'만 판단하고, 실제 입력은 Playwright 같은 코드가 맡게 하면 동작이 안정적이고 디버깅도 쉽습니다.  
   >## 3단계: 이력 데이터 만들기  
   >> 내 이력서를 바탕으로 인적사항, 학력, 경력, 프로젝트, 자격증을 담은 JSON 스키마와 데이터를 만들어 줘. 확인되지 않은 내용은 추측하지 말고 비워둬.  
   >## 4단계: 필드 추출  
   >> URL을 열어 입력 필드의 라벨, 타입, 선택지, 필수 여부를 JSON으로 추출하는 기능만 만들어 줘. 값은 입력하지 말고, 대상 사이트에서 테스트해줘  
   >커스텀 드롭다운, iframe, 여러 페이지로 나뉜 폼에서 문제가 자주 생기니 여기서 충분히 검증하세요.  
   >## 5단계: 필드 매칭  
   >> 추출한 필드와 이력 JSON을 매칭해 값, 근거, 확신도를 출력해 줘. 이력에 없는 값은 지어내지 말고 '확인 필요'로 표시해 줘.  
   >## 6단계: 자동 입력  
   >> 매칭 결과를 폼에 입력해 줘. 텍스트, 드롭다운, 날짜, 파일 업로드를 순서대로 구현하고, 제출 버튼은 절대 누르지 마.  
   >## 7단계: 검토 화면  
   >> 입력한 값, 비어 있는 필드, 확인이 필요한 항목을 한눈에 보여주고, 수정한 뒤 다시 반영할 수 있게 해줘.  
   >## 8단계: 예외 처리와 확장  
   >> 실패한 필드를 기록하고 건너뛰게 해줘. 사이트별 처리는 어댑터로 분리하고, 저장한 테스트 폼으로 회귀 테스트도 만들어 줘.  
   >자기소개서 초안 생성은 이 흐름이 안정된 뒤에 별도 기능으로 추가하는 것이 좋습니다.  
   >## 처음부터 정해둘 원칙  
   >- **제출:** 최종 제출은 항상 사람이 합니다.  
   >- **로그인:** 비밀번호를 코드나 프롬프트에 넣지 말고, 직접 로그인한 브라우저 세션을 사용합니다.  
   >- **개인정보:** LLM에는 매칭에 필요한 정보만 보내고, 주민등록번호 같은 민감 정보는 저장하지 않습니다.  
   >- **사이트 정책:** CAPTCHA는 우회하지 말고 직접 해결합니다. 자동화를 금지하는 약관이 있는지도 미리 확인합니다.  
   >## 지시를 잘 내리는 요령  
   >- 한 번에 한 단계만 요청하고, 완료 기준을 함께 적으세요. 예: "샘플 폼 3개에서 필수 필드를 모두 추출하면 완료"  
   >- 오류가 나면 "안 돼요" 대신 URL, 실패한 필드, 에러 로그, 스크린샷을 함께 주세요.  
   >- 결정한 내용은 `CLAUDE.md`나 `README`에 기록해 두면, 새 대화에서도 같은 맥락으로 이어갈 수 있습니다.  
   >지원할 사이트 2~3개와 선호하는 언어를 알려주시면 1단계부터 바로 시작할 수 있습니다. 특별히 선호하는 언어가 없다면, 빠르게 만들어 보기 좋은 Python과 Playwright 조합을 추천합니다.
